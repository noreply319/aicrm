Evergreen 디자인 시스템

Pipeline CRM의 디자인 토큰과 UI 컴포넌트 카탈로그입니다. Greenhouse 고객지원 사이트의 브랜드 언어(깊은 에버그린, 선명한 그린, 민트 포인트, 둥근 pill 버튼, 세리프 헤드라인)를 참고해 비슷한 결의 자체 브랜드로 정리했습니다. 이 페이지는 앱의 web/app/globals.css를 그대로 불러오므로 실제 화면과 항상 같습니다.

코드: web/components/ui 스타일: web/app/globals.css 와이어프레임: wireframe.html

원칙 · 참고

Greenhouse(support.greenhouse.io) 테마 CSS에서 확인한 값을 출발점으로 삼았습니다. 로고·이름·일러스트 등 Greenhouse 고유 자산은 사용하지 않습니다.

2. 한 번 만들고 재사용버튼·배지·입력·알림·모달은 components/ui만 사용. 화면에서 직접 마크업하지 않습니다.

Button

한 화면(또는 한 모달)에 primary는 하나. 삭제·해제는 danger, 보조 동작은 secondary, 툴바의 가벼운 동작은 ghost.

import { Button, IconButton } from "@/components/ui";

<Button variant="primary" icon="plus" onClick={onAdd}>새 리드</Button>
<Button size="sm" variant="ghost" icon="refresh">새 대화</Button>
<Button variant="danger" onClick={onDelete}>삭제</Button>
<Button href="/api/calendar/connect">다시 연동</Button>      // 외부·OAuth 링크는 <a>로 렌더
<IconButton icon="close" label="닫기" size="sm" onClick={onClose} />
<label className={buttonClass({ size: "sm" })}>파일 업로드<input type="file" hidden /></label>
prop값설명
variantprimary · secondary(기본) · ghost · danger모양
sizemd(36px) · sm(30px)모달 안 목록·툴바는 sm

hrefstring주면 <a>. 앱 내부 이동은 next/link + buttonClass()

Field · Input · Select · Textarea · Checkbox

라벨은 항상 입력 위. 필수는 라벨 끝 *. 보조 설명은 hint(회색). 2열 폼은 .modal-body 또는 .form-grid, 한 줄 전체는 full.

  <Input ref={firstRef} required value={form.company} onChange={…} />
</Field>

Tabs

결정 필요 항목 (명확하지 않았던 부분)

요청에서 정해지지 않은 부분은 아래처럼 기본안으로 구현했습니다. 바꾸려면 알려 주세요.

Q1. 로고·서비스명 — Greenhouse 로고·이름은 쓰지 않고 기존 "◆ Pipeline CRM" 유지(민트 배경 로고 칩 + 세리프 워드마크). 전용 로고가 있으면 교체.
Q2. 폰트 — Greenhouse의 Untitled Sans/Serif는 상용이라 Inter + Source Serif 4(next/font, 무료)로 대체. 세리프는 영문·숫자(브랜드, 지표)에만 사용.
Q3. 사이드바 접기 — 접기 버튼으로 완전히 숨기지 않고 72px 아이콘 레일로 접음(메뉴 이동·펼치기 버튼이 항상 보이도록). 1024px 이하는 자동 레일, 640px 이하 하단 탭. 애니메이션은 html.ui-anim(첫 화면 이후)에서만, 동작 줄이기 설정이면 끔.
Q4. 모바일 프로필 메뉴 — 하단 탭 바에는 4개 메뉴만. 로그아웃·연동 상태는 설정 화면에서.
Q5. 상단 바 구성 — 화면 제목 · 검색 · 테마 · AI Assistant · 추가 버튼. 알림·전역 검색(⌘K)은 범위 밖.
Q6. 추가 예정 메뉴 — 회사·계약서(다른 작업에서 설계 중)는 Sidebar.tsx의 NAV에 한 줄 추가하면 같은 모양으로 들어감. 와이어프레임에 위치만 표시.
Q7. 다크 테마 — Greenhouse에는 다크 테마가 없어 자체 정의(에버그린 계열 어두운 배경 + 밝은 민트 그린 primary).
